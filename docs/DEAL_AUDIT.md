# 斗地主发牌公平性审计

> 审计日期：2026-09-21
>
> 范围：检查当前项目的洗牌、分牌、底牌和席位分布；不修改发牌逻辑，也不把牌力人为调平。

## 结论

当前发牌实现没有发现“偏袒用户”“按牌力筛选”“按结果重发”或把好牌固定给某个席位的问题。生产路径是：创建一副包含 54 张不同物理牌的牌堆，使用 `random.SystemRandom().shuffle(deck)`，然后按 17、17、17、3 张切分给三个席位和底牌。代码没有读取手牌强度，也没有因为牌面好坏重洗或交换席位。

这条路径的统计性质是“每副牌随机”，不是“每副牌均衡”。因此，一家拿到双王、炸弹或很多 A/2，同时另一家牌型松散，是随机发牌允许且必然会出现的结果。把发牌改成尽量平均牌力会改变经典斗地主的分布，并让玩家可以从异常规律中推测发牌策略；不建议在竞技/默认模式加入。

对 50,000 个固定种子牌局和 2,000 个真实 `SystemRandom` 牌局做了内存统计：54 张牌始终唯一且分配为 17/17/17/3；各席位拿到每张物理牌的频率围绕理论值 17/54 波动；底牌频率围绕 3/54 波动；高牌、双王和炸弹的席位均值相互重合。观察到的极端牌力差异符合随机分布，没有证据指向代码偏置。

## 实际代码路径

入口是 [`ddz/game.py`](../ddz/game.py) 的 `Game.deal()`：

```python
deck = list(range(54))
self.rng.shuffle(deck)
self.hands = [sorted(deck[i*17:(i+1)*17], key=...) for i in range(3)]
self.bottom = deck[51:]
```

`Game.__init__` 在未传入测试随机数发生器时使用 `random.SystemRandom()`。服务端的 [`server.py`](../server.py) 创建 `Game()`，因此生产牌桌走操作系统随机源。测试和基准可以显式传入 `random.Random(seed)`，用于复现牌局；这只影响可复现性，不改变生产路径。

排序只改变手牌展示顺序，不改变牌的归属。`first_bid` 在洗牌后单独通过随机数决定首叫位，后续全不叫重发时轮转首叫位；它不参与牌堆切分，也没有根据首叫位修改牌堆。

## 一手资料与算法依据

Python 官方文档将 `random.shuffle(x)` 定义为“原地随机打乱序列”。同一文档说明 `SystemRandom` 使用操作系统提供的随机源，具体由 `os.urandom()` 支持：[Python `random` 文档](https://docs.python.org/3/library/random.html#random.shuffle)、[Python `SystemRandom` 文档](https://docs.python.org/3/library/random.html#random.SystemRandom)。

CPython 当前实现的 `shuffle` 从数组末端向前遍历，在每一步从未处理区间均匀选择一个下标并交换；其 `_randbelow` 使用拒绝采样避免把非二次幂区间映射成有偏结果：[CPython `Lib/random.py`](https://github.com/python/cpython/blob/main/Lib/random.py)。这种 Fisher–Yates 形式的理想随机洗牌定义是每个排列具有相同概率：[NIST Dictionary of Algorithms and Data Structures：ideal random shuffle](https://xlinux.nist.gov/dads/HTML/idealRandomShuffle.html)。

因此，只要随机源在每个选择上提供均匀结果，先生成一副均匀随机排列，再切出前三个 17 张区间和最后 3 张底牌，就等价于不放回随机分配：每个席位得到任意一张物理牌的概率都是 17/54，底牌得到它的概率是 3/54。这个结论描述的是分配概率，不是对某一局牌力的保证。

## 统计方法

统计脚本只在内存中运行，没有写入牌局数据文件，也没有启动服务。

1. 固定种子样本：对 `seed=0..49,999` 分别创建 `Game(random.Random(seed))`，每局只检查初始发牌。
2. 生产路径样本：创建 2,000 局 `Game(random.SystemRandom())`，走与服务端相同的随机源和 `deal()` 代码。
3. 每局检查 `sorted(hands[0] + hands[1] + hands[2] + bottom) == range(54)`，并统计席位/底牌的物理牌频率。
4. “高牌”代理定义为 A、2、小王、大王，共 10 张物理牌；“炸弹”代理定义为某一席位初始 17 张牌中集齐 3 至 2 的四张同点牌；这些指标不是完整牌力评估。
5. 报告中的约 95% 范围使用独立牌局样本的正态近似；跨 162 个“席位 × 物理牌”单元格寻找最大偏差时，最大值本来就会比单个单元格更容易偏离，不能把最大偏差当成单项显著性检验。

## 结果

### 结构和席位分布

| 指标 | 理论值 | 50,000 个固定种子 | 2,000 个 `SystemRandom` | 解读 |
| --- | ---: | ---: | ---: | --- |
| 每局牌数/唯一性 | 54 张、无重复 | 全部通过 | 全部通过 | 没有丢牌、重复牌或跨局残留 |
| 每席位每张物理牌概率 | 17/54 = 0.314815 | 最小 0.309320，最大 0.319860 | 最大绝对偏差 0.0377 | 生产样本较小，波动符合预期 |
| 每张物理牌进入底牌概率 | 3/54 = 0.055556 | 最小 0.052840，最大 0.058080 | 最大绝对偏差 0.0156 | 没有某张牌固定偏向底牌 |
| 每个席位平均高牌数 | 17×10/54 = 3.148148 | 3.14714 / 3.14820 / 3.15052 | 3.1325 / 3.1435 / 3.1665 | 生产样本的席位差仍在抽样误差内 |

固定样本中，单个“席位 × 物理牌”频率的理论 95% 近似范围是 `0.314815 ± 0.00407`；观测到的最大绝对偏差为 0.00549。这个最大值来自同时查看 162 个单元格，不能按一个单元格的 95% 阈值机械判断。

高牌数均值的固定样本 95% 近似误差约为 ±0.0117，三个席位的均值都落在理论均值附近。`SystemRandom` 只有 2,000 局，单席位高牌均值的 95% 误差约为 ±0.06，因此 3.1325 到 3.1665 的差异不足以说明席位偏置。

这里必须使用发牌后的初始 17 张作为横向比较口径。地主确定后会拿走 3 张底牌，地主变成 20 张，农民仍是 17 张；如果叫地主策略又会根据初始手牌强度做选择，那么“最终地主的 20 张高牌数”本身同时包含了张数增加和强牌被选中的条件偏差，不能直接与农民的 17 张高牌数比较。评估发牌公平时应比较三家初始 17 张，或把底牌单独统计；评估叫地主策略时则应明确报告“被选为地主”的条件分布。

### “一家太好、另一家太差”的自然波动

这里先只比较三家初始 17 张牌中“高牌数”的最大值与最小值之差。它是一个容易理解的粗代理，不等于胜率或完整牌力。

| 高牌数最大最小差 | 固定样本占比 |
| ---: | ---: |
| ≥ 3 | 51.582% |
| ≥ 4 | 27.452% |
| ≥ 5 | 11.628% |
| ≥ 6 | 3.678% |
| ≥ 7 | 0.792% |
| ≥ 8 | 0.132% |
| ≥ 9 | 0.004%（2/50,000） |

固定样本的平均高牌差是 2.706，最大观察到 9。也就是说，出现明显的高牌数量差并不反常；“看起来不均”本身不能推出洗牌错误。牌型结构还会进一步放大视觉感受，例如一家的四张同点牌会同时形成炸弹，而另一家可能拿到许多散牌。

### 双王与炸弹代理

理论上，固定一个席位拿到双王的概率是：

```text
(17/54) × (16/53) = 9.5038%
```

50,000 局观察到三个席位分别为 9.400%、9.566%、9.668%；至少一家拿双王的观察概率是 28.634%，理论值约 28.512%。

一个席位在初始 17 张牌中集齐任意一个 3 至 2 的四张同点牌，期望炸弹数为：

```text
13 × C(17,4) / C(54,4) = 0.09783
```

固定样本中三个席位的“至少一组炸弹”概率分别为 9.746%、9.722%、9.482%，平均炸弹数分别为 0.09932、0.09920、0.09686。它们和理论值相符。这里统计的是发牌时已经集齐的纯炸弹，地主取得底牌后可能新增组合；它也不代表牌局最终胜率。

## 是否存在代码级发牌问题

本次检查没有发现以下问题：

- 没有按 `move_score`、叫分结果、模型结果或用户席位筛选牌局；
- 没有“用户拿到差牌就重发”或“AI 拿到好牌就重发”的分支；
- 没有把底牌固定在某个牌值范围，底牌与三个席位使用同一洗牌排列；
- 没有因为排序、首叫位轮转或地主合并底牌而改变初始发牌概率；
- 三家全不叫时会重新洗牌，且首叫位轮转；这是规则层面的新局，不是按牌力条件重发。

需要区分两件事：全不叫后重发会让“这一轮的牌”被作废，但它不是基于牌力判断的重发。若研究“最终进入出牌阶段的牌局”，全不叫局被排除会引入叫牌策略条件偏差；不能用这类条件样本反推原始洗牌是否均匀。

## 建议与边界

默认竞技模式应保持当前随机发牌。若产品以后需要“新手友好”的体验，可以另做明确标注的休闲/教学模式，例如限制连续极端牌局或使用教学牌局；该模式必须公开说明均衡规则、触发条件和边界，不能暗中调牌。隐藏的牌力平衡机制既不是公平保证，也会改变经典规则的分布、影响 AI 评测，并可能让玩家通过历史牌局反推出调牌逻辑。

后续评估 AI 时，应把“发牌公平”和“叫牌/出牌策略”分开统计：使用同一批固定洗牌结果轮换地主和玩家席位，报告地主胜率、农民阵营胜率和叫牌后条件胜率；不要因为一局随机拿到双王就把结果归因于模型策略。高牌、双王和炸弹只能作为发牌健康度的代理指标，不能替代完整的牌力评估。
