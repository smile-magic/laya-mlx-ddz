TABLE RULES

三人一桌，地主对农民。

每人 17 张，底牌 3 张。轮流不叫或叫 1 / 2 / 3 分，必须高于已叫分；3 分立即定地主。全不叫重发。地主拿公开底牌并先出牌，任一农民出完则两位农民一起赢。

出牌与牌型

同牌型、同长度比较主干点数；炸弹压普通牌，王炸最大。连续两家不出后，最后出牌者重新领出，领出不能过牌。顺子至少 5 张，连对至少 3 对，飞机至少 2 组三张；这些连续主体都不能含 2 或王。

支持三带一、三带二、飞机带单 / 对、四带二单 / 两对。飞机单翼允许对子拆单，但不能包含主干点数；对子翼必须点数各不相同。四带二单允许一对。飞机单翼及四带二单都不能同时带双王。四带二不是炸弹。

分数怎么算

叫分为底分。每出一次炸弹 / 王炸翻倍；地主赢且农民都没出过牌为春天，农民赢且地主仅出过一手为反春天，各再翻倍。地主得失为每位农民的两倍，三家得失合计为零。

AI 如何决策

程序生成合法候选，评估拆牌、农民配合和未知手牌采样；Laya 从筛选后的动作中选择。模型未经过斗地主专项训练，采样评分不是真实胜率。模型故障会暂停并允许重试，不会悄悄换成随机 AI。
